# 版本路线

当前正式版本为 **1.2.0**，核心与可选生命周期扩展均已发布；验收按提交和运行轮次分别记录。用户可见变更见 [CHANGELOG](../CHANGELOG.md)，实际设备与消费者结果见[逐版本记录](README.md#开发与维护)，发布操作见[发布指南](RELEASING.md)。

## 1.1.0：页面作用域与稳定性（已发布）

2026-10-13 发布。提供 Activity 页面作用域、可取消延时、窗口约束、系统栏及可选输入法避让、无障碍时长、主题和诊断能力，修复取消、重入及资源清理问题。[Activity 接入](PAGE_SCOPE.md)与[发布归档](releases/1.1.0.md)分别维护使用方式和历史证据。

## 1.2.0：可选运行治理与生命周期扩展（已发布）

- `KToastRuntimePolicy`：显式待处理容量、等待有效期和去重历史 LRU 上限，默认全部关闭。
- `ToastHandle.dropReason`：区分容量拒绝和等待过期，保留旧状态与结束原因枚举。
- 独立 `ktoast-lifecycle`：绑定 LifecycleOwner，Fragment 使用 `viewLifecycleOwner`，停止关闭旧代理、恢复只接受新请求。
- 双模块候选、消费者、签名包与发布门禁，配套使用文档和 Demo。

2026-10-15 发布。[设计与验收约束](design/1.2.0.md)已落实；最终版本 PR 第 32 轮和合并后 main 第 33 轮五版本矩阵通过。正式签名包、Central 批次、正式仓库 60 个文件和 10 份签名、两个正式仓库消费者的 Debug/R8 及 API 37 新进程冒烟已验收。逐轮失败、修正、缓存测量与覆盖限制见[验收记录](releases/1.2.0.md)，不将普通矩阵推广为专用 fixture 或厂商真机覆盖。

## 持续兼容约束

| 层次 | 维护约束 |
| --- | --- |
| Android | 核心 minSdk 21；新平台 API 按版本保护 |
| 核心依赖 | stdlib 1.9.23、Startup 1.1.1；可选能力放在独立模块 |
| 字节码与 metadata | 库 JVM 1.8、Kotlin metadata 1.9；构建 JDK 17 |
| 已发布 API | 保护正式 1.0.5/1.1.0 构造、方法、默认参数及枚举，不隐性改变旧全局行为 |
| 工具链 | AGP 8.6 / compileSdk 36 的官方支持范围风险持续记录，不将压制提示当成认证 |
| 扩展 | 说明实际传递依赖、最低要求及版本配套规则，不让核心接入者承担可选依赖 |

AAR 元数据、JVM 目标和构建成功不能单独证明所有旧消费者可用；依赖解析、Kotlin metadata、R8 和设备运行分别验证。

## 后续评估方向

Compose 专用集成可评估 Host、Composition 清理、Preview 和 View/Compose 混用；依赖及最低版本须由独立模块说明。目前可以从事件或受控副作用调用已有 API，避免在 Composable 函数体直接显示。

多窗口独立并行展示、等待结果接口和其他调度策略尚无确定版本或交付承诺。根据实际业务需求决定范围，不预先引入全局 Flow 总线、复杂优先级或额外依赖。
